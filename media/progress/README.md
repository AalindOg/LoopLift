# LoopLift — four progress reels

Four separate portrait MP4s, one per thematic evidence pack. Each is 43 seconds at 720×1280, 24 fps, H.264 + AAC, with an original instrumental bed. There are no added titles, captions, narration or claimed hours. Original technical labels inside the evidence images remain intact.

## Reels

1. `LoopLift-progress-01-feed-discharge.mp4` — feed/discharge CAD components and seven corresponding audit images.
2. `LoopLift-progress-02-drive-tolerances.mp4` — drive stack, fit analysis and the new expanded coupon study.
3. `LoopLift-progress-03-return-path.mp4` — return tracks, ideal transfer screens, observed geometric interference and separate before/after funnel candidates.
4. `LoopLift-progress-04-print-preparation.mp4` — print-oriented parts, existing mesh/slicer records and prospective physical acceptance plan.

## Scope and honesty

These are videos of actual AI-assisted CAD and computational work, not recordings of 7-hour human sessions. No participant hours are asserted. The planned fourth block was six hours, not seven. Nothing was posted to Half Life.

The current progress-reel modal was not provided. The 43-second portrait cut is an editorial default, not verified compliance with narration, duration or other current platform requirements.

All motion is camera movement around static CAD. There is no simulated working marble loop. The final assembly views show the published baseline, not a secretly installed/approved funnel modification. The separate orange/teal funnel pair shows the original and extended-relief candidate; the candidate's sampled static path cleared but retention, strength and physical operation remain untested. Manufacturing reports are existing computational evidence, not actual printed objects. Small charts support the close-ups; the original full-resolution evidence PNGs should accompany a journal entry when needed.

## Reproduction and checks

`build_reels.py --prepare` tessellates the existing STEP study for the matched-orientation comparison. `--pack N --preview` renders start/mid/end previews; `--pack N` creates and checks a complete video. Run in the CadQuery/VTK environment with `env -u PYTHONPATH`.

Each `reel-NN/` directory contains a shot contract, sampled pre-render and decoded contact sheets, decoded stills and a validation report. All videos were fully decoded with FFmpeg and frame-count checked with ffprobe. Final decoded images were inspected for framing and missing/corrupt content. `DELIVERY-MANIFEST.json` records the four exact videos and hashes.
